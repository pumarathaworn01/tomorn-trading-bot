# คู่มือบอทเทรด BTC (runner.py) 🤖

บอทดูกราฟ BTC/USDT บน Binance TH ตลอดเวลา ใช้กลยุทธ์ 1–5 (แท่ง 4H + กรอง Daily) แล้วทำงานตามโหมดที่เลือก

| ขั้น | โหมด (`config.py → MODE`) | บอททำอะไร | เงินจริง |
|---|---|---|---|
| 1 | `"alert"` | ส่งสัญญาณ + SL/TP/ขนาดไม้ เข้า Telegram | ❌ |
| 2 | `"paper"` (ค่าเริ่มต้น) | เทรดเองด้วยเงินจำลอง $1,000 + แจ้งทุกไม้ + สรุปทุกเช้า | ❌ |
| 3 | `"live"` | เทรดเองบน Binance TH | ✅ — เปิดได้เมื่อผ่านด่านเท่านั้น |

---

## ตั้งค่าครั้งแรก (~10 นาที)

### 1. สร้างบอท Telegram
1. เปิด Telegram → ค้นหา **@BotFather** → กด Start → พิมพ์ `/newbot`
2. ตั้งชื่อบอท (เช่น `Tomorn Trader`) และ username ที่ลงท้ายด้วย `bot` (เช่น `tomorn_btc_bot`)
3. BotFather จะให้ **token** หน้าตาแบบ `123456789:ABCdef...` → คัดลอกไว้
4. ในโฟลเดอร์ `bot/` สร้างไฟล์ชื่อ `.env` (คัดลอกจาก `.env.example`) แล้วใส่:
   ```
   TELEGRAM_TOKEN=123456789:ABCdef...
   ```
   (Terminal: `cp .env.example .env && open -e .env`)

### 2. ผูกบอทกับแชทของคุณ
1. ใน Telegram เปิดแชทกับบอทที่เพิ่งสร้าง → กด Start → พิมพ์ "สวัสดี"
2. ใน Terminal:
   ```
   python3 runner.py --setup-telegram
   ```
   จะขึ้น "เจอแล้ว!" และบอทส่งข้อความ ✅ มาใน Telegram


### 3. ลองเช็กสัญญาณ 1 รอบ
```
python3 runner.py --once
```
ครั้งแรกจะดาวน์โหลดราคาย้อนหลัง 260 วัน (~1 นาที) แล้วบอกว่าแท่ง 4H ล่าสุดมีสัญญาณไหม (ส่วนใหญ่ "ไม่มี" — ปกติ)

### 4. รันจริง
```
caffeinate -i python3 runner.py
```
- `caffeinate -i` = กัน Mac หลับระหว่างบอททำงาน (หน้าจอดับได้ แต่ **ห้ามปิดฝา MacBook** ถ้าไม่ได้ต่อจอ/ไฟ)
- หยุดบอท: กด `Ctrl + C` · เปิดใหม่เมื่อไหร่ก็ได้ บอทจำไม้ที่ถืออยู่ไว้ในโฟลเดอร์ `state/`
- บอทส่ง "🤖 บอทเริ่มทำงาน" ตอนเปิด และ "☀️ สรุปประจำวัน" ทุก 8 โมง — ถ้าเช้าไหนไม่ได้รับ แปลว่าบอทหยุด

## 🌐 เว็บ Tomorn (ดูพอร์ตจำลองแบบเห็นภาพ)
เปิด Terminal อีกหน้าต่าง (บอทยังรันอยู่หน้าต่างเดิม) แล้ว:
```
cd ~/Desktop/Tomorn/projects/crypto-bot/bot
python3 dashboard.py
```
เบราว์เซอร์จะเปิด http://localhost:8080 ให้เอง · ราคาสดจาก Binance TH รีเฟรชทุก 5 วินาที (แท่ง 4H ขวาสุดคือแท่งที่ยังไม่ปิด) · ปิดเว็บด้วย `Ctrl + C` (บอทไม่หยุด)

**เปลี่ยนทุนจำลอง:** แก้ `CAPITAL_USDT` ใน config.py แล้วปิด-เปิดบอทใหม่ — ถ้าพอร์ตจำลองยังไม่มีไม้ บอทจะใช้ทุนใหม่ให้เอง ถ้ามีไม้แล้วและอยากเริ่มใหม่: `python3 runner.py --reset-paper` (ไฟล์เดิมเก็บสำรองไว้ในโฟลเดอร์ state/)

- **ดูบนมือถือ:** `python3 dashboard.py --lan` แล้วเปิดลิงก์ที่ขึ้นว่า 📱 บนมือถือที่ต่อ Wi-Fi เดียวกับ Mac (ครั้งแรก Mac อาจถามว่าอนุญาตให้รับการเชื่อมต่อไหม → กด Allow)
- เว็บ **แสดงผลอย่างเดียว** ไม่สั่งเทรด และข้อมูลไม่ออกนอกบ้าน
- มีอะไรบ้าง: มูลค่าพอร์ต/กำไร/Win rate/Profit Factor · กราฟ BTC แท่ง 4H + EMA20/50 + จุดเข้า-ออกไม้ + เส้น SL/TP ของไม้ที่ถือ · กราฟพอร์ตตามเวลา · ด่านปลดล็อกเงินจริง · ประวัติเทรด · ไฟเขียว/แดงบอกว่าบอทยังทำงานไหม

## คำสั่งที่ใช้บ่อย
| คำสั่ง | ใช้ทำอะไร |
|---|---|
| `python3 runner.py --status` | สถิติเทรดจำลอง + ความคืบหน้าด่านปลดล็อกเงินจริง |
| `python3 runner.py --test-telegram` | ทดสอบส่งข้อความ |
| `python3 runner.py --mode alert` | รันโหมดแจ้งเตือนอย่างเดียว (ไม่ต้องแก้ config) |
| `python3 runner.py --reset-halt` | ปลดล็อกหลัง kill switch หยุดบอท |
| `python3 runner.py --check-live` | ตรวจ API key Binance TH แบบอ่านอย่างเดียว |

---

## 🔒 ระบบความปลอดภัย
- **เสี่ยงไม่เกิน 1% ต่อไม้** (รวมค่าธรรมเนียม 0.10% + slippage 0.02%)
- **ข้ามไม้ที่ R:R หลังหักต้นทุน < 1.5**
- **Kill switch:** พอร์ตลดลง 10% จากจุดสูงสุด → หยุดเปิดไม้ใหม่ + แจ้งเตือน (ไม้ที่ถืออยู่ยังมี SL)
- **ถือได้ทีละ 1 ไม้** เลือกกลยุทธ์ตามลำดับ 1 > 3 > 4 > 2 > 5

## 🔓 ด่านปลดล็อกเงินจริง (ขั้น 3)
บอทจะ **ไม่ยอม** เข้าโหมด live จนกว่าจะครบทุกข้อ (`--status` บอกความคืบหน้า):
1. เทรดจำลอง (paper) ได้ ≥ 30 ไม้ และ Profit Factor ≥ 1.2 — พิสูจน์ว่ากลยุทธ์ทำกำไรได้จริงในตลาดปัจจุบัน
2. `config.py`: `LIVE_ENABLED = True`
3. `.env` มี API key ของ Binance TH (เจ้าของบัญชีสร้างเอง):
   ```
   BINANCE_TH_API_KEY=...
   BINANCE_TH_API_SECRET=...
   ```
   ตอนสร้าง key บน Binance TH → **เปิดแค่ Spot Trading, ห้ามเปิด Withdraw** และถ้าทำได้ ให้จำกัด IP
4. รัน `python3 runner.py --check-live` ให้ผ่าน แล้วเริ่มด้วยเงินน้อย ๆ ก่อน

⚠️ **ข้อจำกัดโหมดเงินจริง:** บอทเฝ้า SL/TP เอง (ไม่ได้วาง stop บนกระดาน เพราะเอกสาร API ของ Binance TH ยังยืนยันคำสั่งแบบนั้นไม่ได้) → ถ้า Mac หลับ/เน็ตหลุด ตอนราคาร่วง **จะไม่มีใครขายที่ SL** · ก่อนใช้เงินจริงจริงจัง แนะนำย้ายบอทขึ้นเซิร์ฟเวอร์ (VPS) ที่เปิดตลอด
