# วิธีรัน Backtest (ใน VS Code)

1. เปิดโฟลเดอร์ `Tomorn` ใน VS Code → เปิด Terminal (Ctrl+` หรือ View → Terminal)
2. พิมพ์:
   ```
   cd projects/crypto-bot/bot
   python3 backtest.py
   ```
   (Windows ใช้ `python` แทน `python3`) — ไม่ต้องติดตั้งอะไรเพิ่ม ใช้ Python 3.8+ ก็พอ
3. รอ 1–3 นาที (ครั้งแรกต้องดาวน์โหลดข้อมูล ~2.6 ปี × 2 เหรียญ ครั้งต่อไปใช้ไฟล์ใน `data/`)
4. ผลอยู่ที่ `results/summary.md` → ใช้ไฟล์นี้เทียบผลแต่ละกลยุทธ์

## รอบ 3 (ทาง ก): ย้อนหลัง 5 ปี หลายเหรียญ
```
python3 backtest.py --years 5 --symbols BTCUSDT,ETHUSDT,SOLUSDT,BNBUSDT,XRPUSDT --costs 0.0012
```
ครอบคลุมขาขึ้น 2021 / ขาลง 2022 → ได้จำนวนไม้มากพอตัดสินกลยุทธ์ 2, 4, 5

## ตัวเลือก
| คำสั่ง | ใช้ทำอะไร |
|---|---|
| (ค่าเริ่มต้น) | A/B บน 1H, กลยุทธ์ 1–5 บน 4H, รันทั้ง cost 0.08% และ 0.12% |
| `--tf 1h` / `--tf 4h` | บังคับทุกกลยุทธ์ใช้ TF เดียว |
| `--costs 0.0012` | ต้นทุนเดียว (0.12% = ค่าธรรมเนียม Binance TH 0.10% + slippage ~0.02%) |
| `--capital 300` | เปลี่ยนทุน |
| `--symbols BTCUSDT` | เทสเหรียญเดียว |
| `--years 1` | ย้อนหลัง 1 ปี |
| `--synthetic` | ทดสอบว่าโค้ดรันได้ (ข้อมูลสุ่ม ผลไม่มีความหมาย) |

## กติกาที่ใช้จำลอง
- A/B รันบน 1H · ทุกกลยุทธ์เข้าที่ราคาเปิดแท่งถัดไปหลังสัญญาณ (ไม่มองอนาคต — ทดสอบแล้ว)
- A/B: TP = 2R (สั่งไว้แค่ SL จึงใช้ R:R 1:2 ตามกลยุทธ์ 1)
- กลยุทธ์ 1–5 รันบน 4H (รวมจากแท่ง 1H) + กรอง Daily ตามที่ออกแบบ
- กลยุทธ์ 1–5 ข้ามไม้ที่ R:R หลังหักต้นทุน < 1.5 (คอลัมน์ "ข้าม") — A/B ไม่กรอง
- S2 TP = แนวต้าน (Swing High) ถัดไปบน Daily ที่ยืนยันแล้ว
- แท่งเดียวกันโดนทั้ง SL และ TP → นับเป็น SL
- แต่ละเหรียญบัญชีแยก $200, ถือทีละ 1 ไม้, Long อย่างเดียว
- Sharpe คิดจากผลตอบแทนรายวัน × √365, อัตราดอกเบี้ยไร้ความเสี่ยง = 0
- แหล่งข้อมูล: ลอง Binance TH ก่อน ถ้าย้อนหลังไม่ถึง 2 ปี จะใช้ข้อมูลสาธารณะของ Binance global (ระบุใน summary.md)
